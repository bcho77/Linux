# 100 Frequently Used Linux Commands

## File & Directory Management

1. `ls` – List directory contents
2. `pwd` – Show current directory
3. `cd` – Change directory
4. `tree` – Display directories as a tree
5. `touch` – Create an empty file
6. `cp` – Copy files or directories
7. `mv` – Move or rename files
8. `rm` – Remove files or directories
9. `mkdir` – Create directories
10. `rmdir` – Remove empty directories
11. `stat` – Show file details
12. `file` – Detect file type
13. `du` – Disk usage of files/directories
14. `df` – Disk space usage
15. `find` – Search files and directories

## File Viewing & Editing

16. `cat` – Display file content
17. `less` – View file page by page
18. `more` – Simple pager
19. `head` – Show first lines of a file
20. `tail` – Show last lines of a file
21. `nano` – Simple text editor
22. `vim` – Advanced text editor
23. `vi` – Classic editor
24. `wc` – Word, line, character count
25. `sort` – Sort file content

## Permissions & Ownership

26. `chmod` – Change file permissions
27. `chown` – Change file owner
28. `chgrp` – Change group ownership
29. `umask` – Set default permissions

## Process Management

30. `ps` – Show running processes
31. `top` – Real-time process viewer
32. `htop` – Enhanced process viewer
33. `kill` – Terminate a process
34. `killall` – Kill processes by name
35. `bg` – Resume job in background
36. `fg` – Resume job in foreground
37. `jobs` – List background jobs
38. `nice` – Set process priority
39. `uptime` – System running time

## Networking

40. `ping` – Test network connectivity
41. `ip` – Network configuration
42. `ifconfig` – Legacy network config
43. `netstat` – Network statistics
44. `ss` – Socket statistics
45. `curl` – Transfer data from URLs
46. `wget` – Download files
47. `scp` – Secure file copy
48. `rsync` – File synchronization
49. `ssh` – Secure remote login

## Package Management (Debian/Ubuntu)

50. `apt` – Package manager
51. `apt-get` – Install packages
52. `apt-cache` – Package search
53. `dpkg` – Debian package tool

## System Information

54. `uname` – System information
55. `hostname` – Show system hostname
56. `whoami` – Current user
57. `who` – Logged-in users
58. `id` – User identity
59. `free` – Memory usage
60. `lsblk` – Block devices
61. `mount` – Mount filesystems
62. `umount` – Unmount filesystems

66. `awk` – Text processing tool

75. `zip` – Create zip archive
